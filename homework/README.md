這套 DPLL 求解器的核心邏輯，就像在做一份「高效率做刪去法的期末分工表」：

SAT 問題要求整份清單中「所有條件（Clause）都必須同時成立」，但每個條件內部只要「其中一項成真」即可。如果用暴力法窮舉所有真偽組合，時間會隨變數增加呈指數級爆炸，因此 DPLL 改用「智慧剪枝的 DFS 回溯搜尋」來解題：

強制推導（單子句消元）： 當某個條件被刪到只剩最後一項時，該變數就別無選擇，必須直接定值。程式會立刻將此結果代入全局——已經被滿足的條件直接整行劃掉，失效的變數則從其他條件中剔除，藉此大幅縮小題目規模。

順水推舟（純文字消元）： 若某變數在所有條件中「只以肯定形式」或「只以否定形式」出現，代表給它符合的形式絕不會使任何條件失效，程式便會直接給值，白撿一個確定項。

假設與回溯（分支探索）： 當無法再靠邏輯直接推導時，程式會挑選一個未定變數嘗試代入 True。若推導過程中出現「整條條件全被否定光」的矛盾衝突，便立刻啟動回溯機制，退回叉路改試 False。

整支程式透過「能確定就先化簡、卡關才做二分猜測、遇到矛盾馬上回頭」的循環，直到所有條件全部被劃掉（成功求解 SAT），或是所有嘗試路徑皆宣告碰壁（證明無解 UNSAT）。
