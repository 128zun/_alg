## 1. 老鼠走迷宮問題 (DFS)

### 🎯 問題描述
給定一個二維網格地圖，其中包含牆壁與通道，老鼠必須從起點 $(0, 0)$ 找到一條通往出口 $(M-1, N-1)$ 的路徑。

### 💡 演算法原理
採用 **深度優先搜尋 (DFS)**：
* **機制**：利用系統遞迴或顯式堆疊（Stack）。演算法會沿著某一方向一路往前探索，直到遇到牆壁或死胡同才回溯（Backtrack）並嘗試其他方向。
* **狀態標記**：使用走過的走廊座標標記（如 `visited` 陣列）避免陷入無窮迴圈。
* **特性**：能夠快速找到「是否有解」，但找到的路徑不保證是最短路徑。

## 2. 狼羊甘藍菜過河問題 (BFS)

### 🎯 問題描述
農夫需要帶著一隻狼、一隻羊和一顆甘藍菜過河。小船一次只能載農夫和一樣物品。
**限制條件**：
* 若農夫不在場，狼會吃羊。
* 若農夫不在場，羊會吃甘藍菜。
求解農夫最少需要過河幾次才能將所有物品安全送到對岸。

### 💡 演算法原理
採用 **廣度優先搜尋 (BFS)**：
* **狀態表示**：使用四元數 $(F, W, S, C)$ 表示狀態，每個變數為 $0$（左岸）或 $1$（右岸）。
* **機制**：使用佇列（Queue）由初始狀態 $(0,0,0,0)$ 開始進行逐層擴展，列舉所有合法的過河轉移狀態。
* **特性**：由於每過一次河的代價相同（權重為 1），BFS 保證能找到**最少過河次數（最短路徑）**。

## 3. 八皇后問題 (DFS + Backtracking)

### 🎯 問題描述
在 $8 \times 8$ 的國際西洋棋盤上放置 8 個皇后，使得任意兩個皇后都不能互相攻擊（即不能處於同一行、同一列或同一斜線上）。

### 💡 演算法原理
採用 **帶剪枝的深度優先搜尋 (DFS + Backtracking)**：
* **機制**：逐行（Row by Row）放置皇后。在第 $i$ 行嘗試將皇后放在第 $j$ 列時，先檢查是否與前 $i-1$ 行已放置的皇后衝突（同行、同列、同對角線）。
* **剪枝 (Pruning)**：若發現衝突，則不再往下搜尋該分支，直接退回上一行嘗試下一列。
* **複雜度降解**：將原本的死搜尋空間 $64^8$ 降為 $8^8$，透過剪枝可在極短時間內找出所有 92 組解。

## 4. NPC 搜尋玩家問題 (A* Search)

### 🎯 問題描述
在 2D/3D 遊戲地圖中，非玩家角色 (NPC) 需要在存在障礙物的環境下，即時計算出追逐玩家的最短路徑。

### 💡 演算法原理
採用 **A* 啟發式搜尋演算法 (A* Search)**：
* **核心公式**：
  $$f(n) = g(n) + h(n)$$
  * $g(n)$：從起點到當前節點 $n$ 的實際移動成本。
  * $h(n)$：從當前節點 $n$ 到目標點（玩家位置）的預估啟發成本（Heuristic）。
* **啟發式函數選擇**：
  * **網格地圖（四方向移動）**：使用曼哈頓距離 (Manhattan Distance)
    $$h(n) = |x_1 - x_2| + |y_1 - y_2|$$
  * **自由移動（八方向/任意角度）**：使用歐幾里得距離 (Euclidean Distance)
* **特性**：結合了 Dijkstra 演算法（保證最短）與貪婪搜尋（提高速度）的優點，適合即時遊戲 Pathfinding。

## 5. IC 設計中的電路繞線問題

### 🎯 問題描述
在晶片實體設計 (Physical Design) 中，需要將晶片上各個邏輯閘的接腳 (Pins) 用金屬導線連接起來，同時需避開障礙物並符合各項 DRC (Design Rule Check) 規範。

### 💡 常用繞線演算法

#### 1. Lee's Algorithm (迷宮繞線法 - Maze Routing)
* **原理**：基於 **BFS** 擴散機制。從源點 (Source) 開始向外一層層標記距離數字（波前擴散 Wavefront Expansion），直到觸及目標點 (Target)，再透過逆向追蹤 (Backtracking) 找出最短線路。
* **優點**：若存在可行路徑，保證能找到最短繞線。
* **缺點**：記憶體與計算時間開銷大。

#### 2. A* 繞線法 (A* Routing)
* **原理**：引進啟發式估計值引導波前向目標方向擴展。
* **優點**：搜尋空間大幅減小，顯著提升繞線速度，為現代 EDA 工具的核心基礎。

#### 3. 通道繞線法 (Channel Routing)
* **原理**：針對專用通道區域，利用左移演算法 (Left-Edge Algorithm) 或約束圖 (Constraint Graph) 排列導線層，避免導線間交叉與短路。

## 6. 演算法比較總結

| 問題名稱 | 使用演算法 | 搜尋類型 | 數據結構 | 是否保證最短路徑 |
| :--- | :--- | :--- | :--- | :--- |
| **老鼠走迷宮** | DFS | 盲目搜尋 (Uninformed) | Stack / 遞迴 | 否 |
| **狼羊甘藍菜** | BFS | 盲目搜尋 (Uninformed) | Queue | 是 |
| **八皇后問題** | DFS + 回溯 | 約束滿足 (CSP) | Stack / 遞迴 | N/A (求解是否存在/列舉解) |
| **NPC 尋路** | A* Search | 啟發式搜尋 (Informed) | Priority Queue | 是 (若 $h(n)$ 可行) |
| **IC 電路繞線** | Lee / A* / Channel | 網格與圖搜尋 | Priority Queue / Grid | 是 (Lee / A*) |
