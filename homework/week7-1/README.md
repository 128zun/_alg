# 旅行推銷員問題 (TSP) 求解策略

旅行推銷員問題（Traveling Salesperson Problem, TSP）是一個經典的組合最佳化問題。由於其路徑組合隨著城市數量呈指數級增長，針對不同的方法有不同的求解策略。

以下為您分別用這五種方法來解析如何解決旅行推銷員問題：

## 1. 貪婪演算法 (Greedy Algorithm / 最近鄰居法)

*   **核心概念**：採取「目光短淺」的策略，每次選擇當前位置距離最近且尚未訪問過的城市，直到走完所有城市再回到起點。
*   **執行步驟**：
    1. 隨機選擇一個起始城市。
    2. 尋找距離目前城市最近的未訪問城市，移動過去。
    3. 重複步驟 2，直到所有城市都被訪問過。
    4. 從最後一個城市返回起始城市。
*   **優缺點**：
    *   **優點**：計算速度極快（時間複雜度為 $O(n^2)$），非常適合處理大規模問題。
    *   **缺點**：容易陷入區域最佳解，最終產生的路徑品質通常較差（可能包含長距離的跨越）。

## 2. 改良法 (Improvement Method / 2-opt 演算法)

*   **核心概念**：先透過貪婪演算法或其他方法得到一個初始路徑，然後透過局部調整（如交換兩條邊）來消除路徑中的交叉，使總距離不斷縮短。
*   **執行步驟**：
    1. 給定一個初始完整路徑。
    2. 檢查路徑中任意兩條邊（例如邊 A-B 與邊 C-D），如果將它們斷開並重新連接（變成 A-C 與 B-D）能讓總長度縮短，則進行替換（稱為 2-opt 交換）。
    3. 重複檢查所有邊組合，直到找不到任何可以縮短路徑的交換方式為止。
*   **優缺點**：
    *   **優點**：能有效修正初始路徑的明顯缺缺陷（如交叉線），結果顯著優於純貪婪演算法。
    *   **缺點**：仍可能停留在區域最佳解，且隨著城市數量增加，計算時間會顯著上升。

## 3. 爬山演算法 (Hill Climbing)

*   **核心概念**：從一個隨機路徑開始，每次微調（例如隨機交換兩個城市的位置）產生一個「鄰近解」。如果鄰近解的總距離比當前解更好，就接受它並取代當前解；如果沒有更好，則繼續嘗試其他鄰近解，直到周圍沒有更好的解為止。
*   **執行步驟**：
    1. 隨機生成或指定一個初始路徑。
    2. 對當前路徑進行微小變動（如交換兩個城市的順序），產生一個鄰居解。
    3. 比較鄰居解與當前解的總距離：若鄰居解較好，則移動到該鄰居解。
    4. 重複上述步驟，直到周圍所有鄰居解都沒有當前解好（到達山頂/區域極值）。
*   **優缺點**：
    *   **優點**：概念簡單、容易實現。
    *   **缺點**：極易受到「區域最佳解」或「平原」的限制，無法跳出局部盲區找到全域最佳解。

## 4. 模擬退火法 (Simulated Annealing, SA)

*   **核心概念**：基於物理學中金屬退火原理。為了克服爬山演算法容易陷入區域最佳解的缺點，它引入了機率接受機制——在演算法初期（高溫時），即使新解比舊解差，也有一定機率被接受；隨著「溫度」逐漸降低，接受劣質解的機率也隨之降低，最終收斂到全域或接近全域的最佳解。
*   **執行步驟**：
    1. 設定初始高溫 $T$ 與冷卻速率。
    2. 隨機產生一個初始路徑，計算其總距離。
    3. 隨機擾動當前路徑產生新路徑，計算距離差 $\Delta E$。
    4. 若新路徑較好（$\Delta E < 0$），直接接受；若較差，以 $e^{-\Delta E / T}$ 的機率決定是否接受。
    5. 降低溫度 $T$，重複步驟 3-4，直到溫度降至極低。
*   **優缺點**：
    *   **優點**：能夠有效跳出區域最佳解，尋找高品質的全域解。
    *   **缺點**：需要調校參數（初始溫度、冷卻率），且計算時間較長。

## 5. 梯度下降法 (Gradient Descent)

*   **核心概念**：標準的梯度下降法是用於連續變數最佳化的方法（透過計算函數的偏微分，沿著梯度的反方向尋找最小值）。然而，TSP 是離散組合最佳化問題，城市順序無法直接求導。
*   **如何應用於 TSP**：
    *   **連續鬆弛與神經網路**：在現代深度學習（如結合神經網路的定向網路 Pointer Networks 或實數座標優化）中，會將離散的路徑選擇轉化為機率分佈或連續座標放寬，建構出可微（Differentiable）的損失函數，然後利用梯度下降法（如 Adam 優化器）來調整模型權重，藉此預測或逼近最佳路徑。
*   **優缺點**：
    *   **優點**：能結合現代深度學習與 GPU 加速，對超大型 TSP 進行快速推論。
    *   **缺點**：無法直接對傳統離散 TSP 使用，必須透過數學變形或機器學習模型來間接實現，實作門檻較高。
